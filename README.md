# 93.1 The Lake — Website Concept

A pitch-ready redesign for WZMJ-FM, 93.1 The Lake in Columbia, South Carolina.

## Highlights

- Prominent live-stream conversion path
- Mobile-first responsive experience
- On-air personality showcase
- Hometown Heroes community feature
- Events, giveaways, and birthday request journeys
- Newsletter interaction and complete contact/footer experience
- Branded Open Graph social preview

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

Built with React, TypeScript, Tailwind CSS, and Vinext.
